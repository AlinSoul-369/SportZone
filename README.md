SportZone 🏆
SportZone is a team-developed sports management platform designed to bring together sports-related services and interactive features in one place.
Features
Sports equipment purchasing
Sports facility reservations
Match prediction interface
User and admin interfaces

Getting Started
The project contains separate applications for the admin dashboard, user interface, and server.
To run the project locally, install the dependencies in each application directory and follow the available configuration instructions.
